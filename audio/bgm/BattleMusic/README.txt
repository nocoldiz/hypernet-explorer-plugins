Custom Battle Music
===================

Drop your own battle music files into this folder to add them as selectable
battle tracks in the game.

How to use
----------
1. Copy audio files into this folder (audio/bgm/BattleMusic/).
2. Supported formats: .ogg (recommended), .m4a, .mp3, .wav.
3. Launch the game. Each file appears as a track named after its filename in
   every battle music selector:
     - Options menu  -> "Battle Music"
     - The standalone Music Selection screen
     - Character creation -> settings step -> "Battle Music"

Notes
-----
- The track name shown is the filename without its extension, so name your
  files clearly (e.g. "Boss Theme.ogg" shows up as "Boss Theme").
- Custom tracks are listed under the composer label "Custom".
- Only works in the desktop (downloadable) version of the game; browser builds
  cannot read this folder.
- Files are scanned at startup. Add files before launching, then restart the
  game to pick up new ones.
